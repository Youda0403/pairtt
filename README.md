# Pairframe

레트로 다이너 메뉴판 컨셉의 **페어 포스터 메이커**. 두 사람을 "오늘의 스페셜"처럼
소개하는 세로형 메뉴판을 만들고, 고화질 PNG(3000 × 4500)로 저장할 수 있습니다.

빌드 도구도 서버도 필요 없는 정적 사이트입니다.

## 기능

| | |
|---|---|
| 간판 | 페어 이름(큰 글씨) · 아치 문구 · 알약 문구 |
| 가운데 그림 | 두 사람 그림/사진. 드래그로 위치, 휠·두 손가락·슬라이더로 확대 |
| 캐릭터 01 · 02 | 원형 초상 + 이름 |
| 문구 | 위 2덩어리 · 아래 2덩어리. `/` 로 줄을 나눕니다 |
| 메뉴판 | 3단 29줄은 고정. `SPECIAL PAIR SET` 첫 줄만 두 사람 것으로 바뀝니다 |
| 음식 그림 | 버거 · 피자 · 밀크셰이크. 투명 PNG로 교체하고 끌어 옮길 수 있습니다 |
| 색상 | 크림 · 레드 · 서브 · 포인트 4그룹 + 프리셋 3종 |
| 한글 | 한글을 입력하면 영문 폰트와 어울리는 한글 폰트로 자동 전환됩니다 |
| 저장 | 3000 × 4500 PNG. 폰트와 그림을 파일 안에 심어 어디서 열어도 그대로입니다 |

입력값·색상·사진은 브라우저 `localStorage`에 남아 새로고침해도 유지됩니다.

## 실행

파일을 `file://` 로 직접 열면 폰트·그림 임베드용 `fetch`가 막혀 저장이 깨집니다.
반드시 HTTP로 띄우세요.

```sh
python3 -m http.server 8000
# http://localhost:8000
```

배포는 정적 호스팅 어디든 그대로 올리면 됩니다 (GitHub Pages, Cloudflare Pages, Netlify …).

## 파일

```
index.html   UI 골격 + 포스터 전체(인라인 SVG). 디자인 수정은 대부분 여기서 한다.
style.css    편집 화면 스타일. 포스터 자체의 색은 여기 없다(app.js가 주입).
app.js       상태 관리, 텍스트 배치, 사진 조작, 색상 주입, PNG 내보내기.
fonts/       라틴 3종(Alfa Slab One/Yellowtail/Oswald) + 한글 3종(Jua/Gaegu/Gothic A1).
             모두 OFL 1.1, fonts/OFL.txt 참고.
art/         음식 그림 3종(PNG). 직접 그린 그림입니다.
```

## 구조 메모

- 포스터는 `viewBox="0 0 1000 1500"` 인라인 SVG **하나**입니다.
  화면에 보이는 것과 저장되는 것이 같은 SVG라 미리보기와 결과물이 어긋나지 않습니다.
- 색은 SVG 안의 `<style id="theme-style">`에 `app.js`가 통째로 써넣습니다.
  `.f-red`(fill) / `.s-red`(stroke) 같은 클래스만 쓰고 색을 직접 박지 않습니다.
- 조절 항목은 4개(크림·레드·서브·포인트)뿐이고, 카드 종이색·먹색·얼룩·띠 위 글자색은
  자동 계산합니다.
- 알약·리본·이름 바는 글자 폭을 재서 JS가 크기를 잡습니다. 문구를 바꿔도 따라옵니다.
- 저장은 SVG를 복제 → 그림을 data URI 로, 폰트를 base64 로 심고 → `<img>`로 읽어
  캔버스에 3배로 그린 뒤 `toBlob`으로 내려받습니다. 외부 라이브러리를 쓰지 않습니다.

### 주의할 점

- SVG를 문자열로 직렬화할 때는 **XML 규칙**을 따릅니다. 주석 안에 하이픈 두 개(`--`)가
  있으면 파싱이 깨져 저장이 통째로 실패합니다.
- `art/` 그림은 파일 참조라 저장 전에 data URI 로 바꿔 심습니다(`inlineArt`).
- 포스터 요소의 `display`는 `app.js`가 인라인으로 직접 지정합니다. `style.css`에
  `display:none` 규칙을 되살리면 화면에서는 사진이 사라지고 저장본에만 남습니다.
- 음식 그림 색은 그려진 그대로라 테마를 따르지 않습니다.
- 한글 폰트는 한 벌에 230~460KB라 실제로 한글이 쓰인 역할의 폰트만 내려받고
  저장본에 심습니다.
- 업로드 이미지는 가운데 2000px / 초상 1100px / 음식 900px로 줄여서 담습니다.
