# Pairframe

레트로 다이너 메뉴판 컨셉의 **페어 포스터 메이커**. 두 사람을 "오늘의 스페셜 메뉴"처럼
소개하는 세로형 메뉴판을 만들고, 고화질 PNG(3000 × 4500)로 저장할 수 있습니다.

빌드 도구도 서버도 필요 없는 정적 사이트입니다. 파일 3개(+폰트)가 전부입니다.

## 기능

| | |
|---|---|
| 간판 | 페어 이름(로고) · 부제(DINER & GRILL) · 설립 연도 · 상단 문구 |
| 메인 사진 | `TODAY'S SPECIAL` 사진. 드래그로 위치, 휠·두 손가락·슬라이더로 확대 |
| 캐릭터 01 · 02 | 다이너 사원증 카드: CREW MEMBER 밴드 + 이름 + 초상 + AGE / JOB · LIKES · TODAY'S PICK + 바코드 |
| TODAY'S PICK | 비워 두면 상대 캐릭터의 이름이 자동으로 들어갑니다 |
| 오늘의 메뉴 | 메뉴 4줄(한 줄로 이어짐) · 손글씨 메모 3줄 · 가운데/맨 아래 문구 |
| 스티커 | 밀크셰이크 / 햄버거 / 감자튀김 3칸을 배경 투명 PNG로 교체.<br>올린 뒤 포스터 위에서 끌어 옮기고 0.3~3배로 확대·축소 |
| 색상 | 크림 · 레드 · 그린 · 캐릭터 01 · 캐릭터 02 · 포인트 6그룹 + 프리셋 3종 |
| 한글 | 한글을 입력하면 영문 폰트와 어울리는 한글 폰트로 자동 전환됩니다 |
| 저장 | 3000 × 4500 PNG. 폰트를 파일 안에 심어 어디서 열어도 글꼴이 유지됩니다 |

입력값·색상·사진은 브라우저 `localStorage`에 남아 새로고침해도 유지됩니다.

## 실행

파일을 `file://` 로 직접 열면 폰트 임베드용 `fetch`가 막혀 저장 품질이 떨어집니다.
반드시 HTTP로 띄우세요.

```sh
python3 -m http.server 8000
# http://localhost:8000
```

배포는 정적 호스팅 어디든 그대로 올리면 됩니다 (GitHub Pages, Cloudflare Pages, Netlify …).

## 파일

```
index.html   UI 골격 + 포스터 전체(인라인 SVG). 디자인 수정은 대부분 여기서 한다.
style.css    편집 화면 스타일. 포스터 자체의 색은 여기 없다(app.js가 주입).
app.js       상태 관리, 텍스트·배너 배치, 사진 조작, 색상 주입, PNG 내보내기.
fonts/       라틴 3종(Pacifico/Caveat/Nunito) + 한글 3종(Jua/Gaegu/Gothic A1).
             모두 OFL 1.1, fonts/OFL.txt 참고.
```

## 구조 메모

- 포스터는 `viewBox="0 0 1000 1500"` 인라인 SVG **하나**입니다.
  화면에 보이는 것과 저장되는 것이 같은 SVG라 미리보기와 결과물이 어긋나지 않습니다.
- 포스터는 인쇄물처럼 비율이 고정된 작품이라 화면 폭에 맞춰 **통째로 축소**만 됩니다.
  모바일에서 세로로 쌓이는 것은 편집 패널 쪽입니다.
- 상자는 사진 한 장과 사원증 카드 2장뿐입니다. 나머지는 기둥(x 64~936)을 관통하는
  가로 괘선과 거기에 물린 깃발 라벨로 묶고, 씰·메달·음식이 그 선을 가로지릅니다.
- 색은 SVG 안의 `<style id="theme-style">`에 `app.js`가 통째로 써넣습니다.
  `.f-red`(fill) / `.s-red`(stroke) 같은 클래스만 쓰고 색을 직접 박지 않습니다.
- 조절 항목은 6개(크림·레드·그린·캐릭터1·캐릭터2·포인트)뿐이고,
  카드 종이색·먹색·사진 자리 연두·띠 위 글자색은 자동 계산합니다.
- 배너와 리본은 글자 폭을 재서 JS가 `path`를 그립니다. 문구를 바꿔도 띠가 따라옵니다.
- 저장은 SVG를 복제 → 폰트를 base64로 심고 → `<img>`로 읽어 캔버스에 3배로 그린 뒤
  `toBlob`으로 내려받습니다. 외부 라이브러리를 쓰지 않습니다.

### 주의할 점

- SVG를 문자열로 직렬화할 때는 **XML 규칙**을 따릅니다. 주석 안에 하이픈 두 개(`--`)가
  있으면 파싱이 깨져 저장이 통째로 실패합니다. `stripComments()`가 방어하지만,
  SVG 안에 새 주석을 넣을 때 구분선을 `---`로 그리지 마세요.
- 포스터 요소의 `display`는 `app.js`가 인라인으로 직접 지정합니다. `style.css`에
  `display:none` 규칙을 되살리면 화면에서는 사진이 사라지고 저장본에만 남습니다.
- `TODAY'S SPECIAL` 깃발과 스티커는 겹칠 대상보다 **뒤에** 그려야 위로 올라옵니다.
- 음식(빵·패티·치즈·양상추·감자튀김) 색은 테마를 따르지 않는 고정값입니다.
- 한글 폰트는 한 벌에 230~460KB라 실제로 한글이 쓰인 역할의 폰트만 내려받고
  저장본에 심습니다.
- 업로드 이미지는 메인 2200px / 캐릭터 1100px / 스티커 900px로 줄여서 담습니다.
